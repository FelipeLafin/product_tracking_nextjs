# Product Tracking App

Aplicação de rastreamento construída com **Next.js + React + TypeScript**.

## Executar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Estrutura

- `app/` — entrada do Next.js.
- `src/App.tsx` — composição/navegação principal.
- `src/components/screens/` — telas da aplicação.
- `src/components/shared/` — componentes reutilizáveis.
- `src/data/` — dados estáticos usados pela interface.

Os diretórios `node_modules/` e `.next/` são gerados localmente e não fazem parte do projeto versionado.
